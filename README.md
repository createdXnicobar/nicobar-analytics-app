# nicobar-analytics-app
This repository contains all the code. assets, and documentation for the Nicobar analytics app for in-store trial data

# Description
Mobile analytics platform deployed across all Nicobar offline stores to capture trial-room behavior and derive important metrics.

# Tech Stack
FastAPI, Python, React Native, typescript, AWS

# Features
Cross-platform app with in-store barcode scanning, basket-based trial submission, backend for trial and purchase ingestion, SKU trial-to-purchase matching using time-window logic, computation of key metrics, analytics dashboards, seamless integration with Nicobar product and checkout APIs, high-volume event storage
